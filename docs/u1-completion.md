# U1 completion and deferrals

U1 delivers the reproducible TypeScript/React/Vite skeleton, immutable F1 consumer snapshot,
Request/Result client, deterministic fake transport, status taxonomy, pagination boundary,
`ui.official.web` process package shell, static-asset packaging, security design interfaces, and
offline verification.

Deferred by design:

- U2 Dashboard, Plugins, Capabilities, Runtime, and Audit pages;
- U3 Grant/configuration/lifecycle and other mutations;
- real Core control-channel connection and installation/lifecycle integration;
- any actual HTTP listener, pairing flow, cookie issuance, or production Web-security claim;
- public release licensing, package signing, and real credentials.

The package does not import Core, contain Core SQLite paths, expose a product business page, or retain
authoritative Core state.
